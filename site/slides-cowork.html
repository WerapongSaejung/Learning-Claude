ก่อนจะให้ AI ทำงานแทนเรา ต้องรู้จักเครื่องมือให้ครบทุกปุ่มก่อน

Part 1 · พื้นฐาน

Claude คืออะไร?

Claude คือ AI ผู้ช่วยอัจฉริยะ พัฒนาโดยบริษัท Anthropic (สหรัฐอเมริกา) เน้นความปลอดภัยและความน่าเชื่อถือ

  1. คุยโต้ตอบได้เหมือนคนถาม-ตอบ วิเคราะห์ สรุป แปลภาษา รวมถึงภาษาไทย
  2. เข้าใจไฟล์และรูปภาพอ่าน PDF, เอกสาร, ตาราง, รูปถ่าย แล้ววิเคราะห์ให้ได้
  3. ลงมือทำงานได้จริงเขียนโค้ด สร้างไฟล์ ค้นเว็บ — ไม่ใช่แค่ตอบข้อความ

UI พื้นฐาน — หน้าแชทหลัก

  1. ช่องพิมพ์ข้อความ (Prompt box)หัวใจของทุกอย่าง — พิมพ์สิ่งที่อยากได้ กด Enter ส่ง / Shift+Enter ขึ้นบรรทัดใหม่

Chat vs Cowork vs Code

Claude มี 3 โหมดการทำงาน — ต่างกันตรง "ใครเป็นคนลงมือทำ"

Part 2 · 3 โหมด

ภาพรวม 3 โหมด — ต่างกันอย่างไร

💬 Chat🤝 Cowork⌨️ Code
บทบาทของ Claudeที่ปรึกษา — บอกวิธีผู้ช่วย — ลงมือทำให้วิศวกร — ทำครบวงจร
เข้าถึงไฟล์ในเครื่องเฉพาะไฟล์ที่แนบ✓ ทั้งโฟลเดอร์ที่เลือก✓ ทั้งโปรเจค
สร้าง/แก้ไฟล์จริง—✓✓ + Git version
รันและทดสอบโค้ด—✓ ใน sandbox✓ ในเครื่องจริง
เหมาะกับถาม-ตอบ ไอเดีย ร่างงานงานเอกสาร วิเคราะห์ อัตโนมัติพัฒนาซอฟต์แวร์จริงจัง

💬Claude ตอบ = "แค่บอก"

อธิบายขั้นตอน + เขียนโค้ดตัวอย่างให้ในแชท

แต่คุณต้องเอาไปสร้างไฟล์ ติดตั้ง รันเองทั้งหมด

เหมาะเมื่อ

  • อยากเรียนรู้และเข้าใจก่อน
  • ขอไอเดีย เปรียบเทียบทางเลือก
  • งานสั้นๆ copy โค้ดไปใช้เองได้

🤝 Cowork — "อยากสร้างเว็บด้วย Flask"

คุณพิมพ์
อยากสร้างเว็บด้วย Flask

🤝Claude = "สร้างให้เลย"

สร้างไฟล์ app.py, templates, ทดลองรันใน sandbox ตรวจว่าทำงานได้ แล้ววางไฟล์ทั้งหมดลงโฟลเดอร์ในเครื่องคุณ — เปิดใช้ได้ทันที

เหมาะเมื่อ

  • อยากได้ "ผลลัพธ์" ไม่ใช่แค่คำแนะนำ
  • งานหลายขั้นตอน เช่น อ่านไฟล์ → วิเคราะห์ → สร้างรายงาน
  • ไม่ใช่โปรแกรมเมอร์ก็ใช้ได้

⌨️ Code — "อยากสร้างเว็บด้วย Flask"

คุณพิมพ์
สร้างโปรเจคเว็บ Flask พร้อมระบบล็อกอิน

⌨️Claude = "ทำครบวงจร"

สร้าง + แก้ + เก็บ version (Git) + เขียนเทสต์ + รันทดสอบจริง ในเครื่องคุณ วนแก้จนผ่าน เหมือนมีโปรแกรมเมอร์นั่งข้างๆ

เหมาะเมื่อ

  • โปรเจคซอฟต์แวร์จริงจัง มีหลายไฟล์
  • ต้องแก้โค้ดเดิม ทดสอบ รันจริง
  • ใช้ร่วมกับ Git / Terminal (Workshop 5)
Part 2 · 3 โหมด

สรุปง่ายๆ — เลือกโหมดไหนดี?

  1. อยากรู้ / อยากได้คำตอบ → 💬 Chat "Flask คืออะไร"  "ช่วยร่างอีเมลหน่อย"  "สรุป PDF นี้ให้"
  2. อยากได้ไฟล์งานสำเร็จ / ทำงานกับไฟล์ในเครื่อง → 🤝 Cowork "วิเคราะห์ยอดขายใน Excel แล้วทำสไลด์ให้"  "จัดระเบียบโฟลเดอร์นี้"
  3. อยากพัฒนาโปรแกรมจริงจัง → ⌨️ Code "สร้างเว็บแอป Flask ทดสอบและรันให้ด้วย"
💡 จำง่ายๆ: Chat = ปาก, Cowork = มือ, Code = ทีมวิศวกร

โควตาการใช้งาน — ใช้ยังไงให้คุ้ม

⏳โควตารีเซ็ตเป็นรอบ

ทุกแผนมีลิมิตการใช้งานต่อรอบเวลา (~5 ชั่วโมง) ใช้หมดต้องรอรอบถัดไป — วางแผนงานใหญ่ให้ดี

✂️แชทยาว = เปลืองโควตา

ทุกข้อความ Claude ต้องอ่านประวัติทั้งหมดซ้ำ — เปลี่ยนเรื่องเมื่อไหร่ เปิด New Chat

📋รวมคำสั่งเป็นข้อความเดียว

บอกให้ครบในครั้งเดียว ดีกว่าถามทีละนิด 10 รอบ

📉เลือกโมเดลให้เหมาะ

งานง่ายใช้โมเดลเล็ก ประหยัดโควตาไว้ให้งานยาก

เขียน Prompt อย่างไรให้ได้งานดี

  1. บอกให้ชัด: อะไร + รูปแบบไหน + เท่าไหร่ ❌ "ทำสไลด์หน่อย" → ✅ "ทำสไลด์นำเสนอผู้บริหาร 10 หน้า ธีมสีเข้ม บันทึกเป็น HTML"
  2. ให้บริบทและตัวอย่าง "กลุ่มเป้าหมายคือเด็กประถม" / "เขียนโทนเดียวกับตัวอย่างนี้…"
  3. บอกบทบาท (Role) "สมมติว่าคุณเป็นเลขาจดบันทึกการประชุม…" — ใช้จริงใน Workshop #6
  4. ทำงานใหญ่ทีละขั้น Prompt 1 สร้างข้อมูล → Prompt 2 เอาไปทำสไลด์ (แบบ Workshop #4)
  5. ไม่พอใจ = สั่งแก้ต่อได้เลย "ขอสีสว่างกว่านี้" "ตัดข้อ 3 ออก" — ไม่ต้องเริ่มใหม่

ที่เหนือกว่า AI แชทธรรมดาทั่วไป — เพราะ Cowork ไม่ได้แค่ "ตอบ" แต่ "ทำงาน"

Part 3 · ความสามารถที่ 1/10

① เข้าถึงไฟล์จริงในเครื่องคุณ

AI ทั่วไปเห็นแค่ไฟล์ที่คุณอัพโหลดทีละไฟล์ แต่ Cowork อ่าน เขียน แก้ไข ทั้งโฟลเดอร์ที่คุณอนุญาต

ตัวอย่างงานจริง

  • "เปลี่ยนชื่อรูป 500 ไฟล์ตามวันที่ถ่าย"
  • "อ่านรายงานทุกไฟล์ในโฟลเดอร์แล้วสรุปรวม"
  • "จัดไฟล์ในโฟลเดอร์ Downloads ให้เป็นหมวดหมู่"
📁
Part 3 · ความสามารถที่ 2/10

② ทำงานหลายขั้นตอนแบบอัตโนมัติ (Autonomous)

สั่งครั้งเดียว Cowork วางแผน → ลงมือ → ตรวจสอบ → แก้ไข เองจนจบ พร้อม Task list ให้เห็นความคืบหน้า

ตัวอย่าง: "วิเคราะห์ยอดขายแล้วทำสไลด์"

  • 1. อ่านไฟล์ Excel → 2. เขียนโค้ดวิเคราะห์ → 3. รันหาข้อมูลเด่น → 4. สร้างสไลด์ → 5. ตรวจความถูกต้อง
  • ทั้งหมดนี้จาก prompt เดียว
🔄
Part 3 · ความสามารถที่ 3/10

③ สร้างไฟล์เอกสารจริง ใช้งานได้ทันที

📝Word

.docx รายงาน จดหมาย พร้อมจัดรูปแบบ

📊Excel

.xlsx พร้อมสูตร กราฟ (Workshop #4)

🎬PowerPoint

.pptx สไลด์นำเสนอ

📄PDF

สร้าง รวม แยก กรอกฟอร์ม

🌐รวมถึง HTML + JavaScript

เว็บ เกม สไลด์อินเทอร์แอคทีฟ — เปิดในเบราว์เซอร์ได้เลย ไม่ต้องมีโปรแกรมพิเศษ (ใช้เกือบทุก Workshop วันนี้)

Part 3 · ความสามารถที่ 4/10

④ รันโค้ดได้จริงใน Sandbox ปลอดภัย

Cowork มี คอมพิวเตอร์ Linux จำลอง ในตัว — เขียนโค้ด Python/JavaScript แล้วรันทดสอบจริงก่อนส่งงาน

ต่างจาก AI ธรรมดายังไง

  • AI ธรรมดา: เขียนโค้ดให้ แต่ไม่รู้ว่ารันได้จริงไหม
  • Cowork: รันเอง เจอ error แก้เอง จนได้ผลลัพธ์ถูกต้อง
  • ปลอดภัย: sandbox แยกจากเครื่องจริงของคุณ
🧪
Part 3 · ความสามารถที่ 5/10

⑤ ค้นเว็บและวิจัยข้อมูลสด

ค้นหาข้อมูลล่าสุดจากอินเทอร์เน็ต อ่านหลายแหล่ง เปรียบเทียบ แล้วสรุปเป็นรายงานพร้อมแหล่งอ้างอิง

ตัวอย่างงานจริง

  • "หาราคาคู่แข่ง 5 เจ้าแล้วทำตารางเปรียบเทียบ"
  • "เทรนด์สินค้าเกษตรใน Reddit/Etsy/Amazon" (Workshop #8)
  • "ข่าวอุตสาหกรรมสัปดาห์นี้ สรุปเป็น 1 หน้า"
🔍
Part 3 · ความสามารถที่ 6/10

⑥ ตั้งเวลาทำงานอัตโนมัติ (Scheduled Tasks)

สั่งครั้งเดียว ให้ทำงานซ้ำตามเวลา — ทุกเช้า ทุก 3 ชั่วโมง ทุกวันจันทร์ — โดยไม่ต้องมานั่งสั่งเอง

ตัวอย่างงานจริง

  • "ทุกเช้า 6 โมง สรุปข่าวให้ฉัน"
  • "ทุก 3 ชม. หาข้อมูลสินค้าใหม่แล้วบันทึกไฟล์" (Workshop #8)
  • "เตือนฉันอีก 1 ชั่วโมงให้ส่งอีเมล"

Part 3 · ความสามารถที่ 7/10

⑦ เชื่อมต่อแอปที่คุณใช้ (Connectors / MCP)

เชื่อม Claude เข้ากับ Gmail, Google Drive, Slack, Notion, ปฏิทิน และแอปอื่นๆ — ให้อ่านและทำงานในแอปเหล่านั้นแทนคุณ

ตัวอย่างงานจริง

  • "สรุปอีเมลที่ยังไม่ได้อ่านเมื่อวาน"
  • "ดูปฏิทินแล้วช่วยเตรียมประชุมพรุ่งนี้"
  • "ส่งสรุปงานเข้า Slack ทีม"
🔌
Part 3 · ความสามารถที่ 8/10

⑧ ควบคุมเบราว์เซอร์และหน้าจอแทนคุณ

ผ่าน Chrome Extension และ Computer Use — Claude เปิดเว็บ คลิก กรอกฟอร์ม อ่านหน้าจอ ได้เหมือนมีคนนั่งทำให้

ตัวอย่างงานจริง

  • "เข้าเว็บนี้แล้วเก็บราคาสินค้ามาให้"
  • "กรอกฟอร์มนี้จากข้อมูลใน Excel"
  • สอนใช้โปรแกรมบนหน้าจอแบบชี้ทีละขั้น

⑩ แตกทีมย่อยทำงานคู่ขนาน (Agents)

งานใหญ่ Cowork แบ่งให้ agent ย่อยหลายตัวทำพร้อมกัน เช่น ตัวหนึ่งค้นข้อมูล อีกตัวตรวจสอบ อีกตัวเขียนรายงาน

🏆สรุป: ทำไม Cowork ถึง "Autonomous"

Cowork = มอบหมายงาน แล้ว AI วางแผน ลงมือ ตรวจสอบ ส่งมอบ — คุณเป็นคนตรวจรับ

04

Skill & Connector

ต่อความสามารถให้ Claude — สอนวิธีทำงานแบบของเรา และเชื่อมเข้ากับแอปที่เราใช้อยู่

Part 4 · Skill

Skill คืออะไร และทำไมถึงสำคัญ

Skill คือ คู่มือการทำงานที่เราเขียนให้ Claude อ่าน — บอกว่างานประเภทนี้ในองค์กรเรา ทำตามขั้นตอนไหน ใช้ฟอร์แมตอะไร ห้ามพลาดตรงไหน

😩ไม่มี Skill

ทุกครั้งที่สั่งงาน ต้องพิมพ์อธิบายขั้นตอนและฟอร์แมตใหม่หมด — ยาว ลืมง่าย และแต่ละคนสั่งไม่เหมือนกัน

✅มี Skill

พิมพ์สั้นๆ ว่า "ทำรายงานประจำเดือน" — Claude หยิบคู่มือขึ้นมาอ่านเอง แล้วทำตามมาตรฐานเดียวกันทุกครั้ง ทุกคน

💡คิดง่ายๆ แบบนี้

Skill = SOP ของบริษัท ที่เขียนให้ AI อ่านรู้เรื่อง — เขียนครั้งเดียว ใช้ได้ทั้งทีม และแก้ที่เดียวได้ทั้งระบบ

Part 4 · Skill

โครงสร้างของ Skill — มีแค่ 3 ส่วน

  1. ชื่อ (name)ชื่อสั้นๆ ของทักษะนี้ เช่น monthly-sales-report
  2. คำอธิบาย (description)บอกว่า "ใช้เมื่อไหร่" — สำคัญที่สุด เพราะ Claude ใช้ตัดสินใจว่าจะหยิบ Skill นี้ขึ้นมาใช้ไหม
  3. เนื้อหาคู่มือขั้นตอน ฟอร์แมตที่ต้องการ ตัวอย่าง และข้อห้าม — เขียนเป็นภาษาคนธรรมดาได้เลย
ไฟล์ SKILL.md — หน้าตาประมาณนี้
---
name: monthly-sales-report
description: ใช้เมื่อผู้ใช้ขอสรุปยอดขายประจำเดือน
---
1. อ่านไฟล์ยอดขาย
2. เทียบกับเดือนก่อน
3. สรุปเป็นตาราง + 3 ประเด็น
Part 4 · Skill

Skill ที่แนะนำให้ติดตั้ง

📄ชุดสร้างเอกสาร (มีมาให้แล้ว)

docx / xlsx / pptx / pdf — เปิดใช้จากหน้า Settings แล้ว Claude จะสร้างไฟล์ Office ได้สวยและถูกฟอร์แมต ต้องเปิด code execution และ file creation ก่อน

🧠Karpathy

บังคับให้ Claude อธิบายเรื่องยากแบบ "สอนจากศูนย์" — ไล่จากหลักการ ไปตัวอย่าง ไปข้อควรระวัง เหมาะกับตอนอยากเข้าใจจริง ไม่ใช่แค่ได้คำตอบ

🎤Grill me

สลับบทบาท: ให้ Claude ซักเรากลับทีละคำถาม ก่อนลงมือทำ — ใช้ตอนโจทย์ยังไม่ชัด จะได้ไม่ได้งานที่ "สวยแต่ผิดโจทย์" (หลักสูตรนี้ก็ออกแบบด้วยวิธีนี้)

✍️Skill ของคุณเอง

เอา SOP / ฟอร์มรายงาน / สไตล์การเขียนของบริษัท มาเขียนเป็น Skill — นี่คือจุดที่ได้เปรียบจริง

Part 4 · Skill

Skill มาจากไหนได้บ้าง — 3 ทาง

  1. ของที่ Anthropic ทำมาให้ชุดสร้างเอกสาร Office และอื่นๆ — แค่เปิดสวิตช์ในหน้า Settings ก็ใช้ได้ทันที
  2. Skill Directory ในตัวแอปCustomize → Skills → ปุ่ม + → Browse skills แล้วเลือกติดตั้ง
  3. อัปโหลดเอง (.zip)ทำโฟลเดอร์ที่มีไฟล์ SKILL.md แล้วบีบเป็น .zip อัปโหลดเข้าไป — ใช้ได้ทั้ง Skill ที่เราเขียนเอง และที่โหลดจากชุมชน
ข้อควรระวัง: Skill ที่โหลดมาจากภายนอกคือคำสั่งที่ Claude จะทำตาม — อ่านเนื้อหาก่อนติดตั้งทุกครั้ง เหมือนที่เราไม่ติดตั้งโปรแกรมจากแหล่งที่ไม่รู้จัก
Part 4 · Connector

MCP / Connector / Plugin — ต่างกันยังไง

🧰Skill

สอนวิธีทำ
คู่มือการทำงาน — ไม่ต่อกับระบบภายนอก

🔌Connector

ต่อกับแอป
Gmail, Drive, Calendar, Slack, Notion — ให้ Claude อ่านและทำงานในแอปนั้นได้

🔗MCP

มาตรฐานเบื้องหลัง
ภาษากลางที่ทำให้ Claude คุยกับระบบอื่นได้ — Connector ส่วนใหญ่สร้างบนมาตรฐานนี้

📦Plugin

ชุดรวม — เอา Skill + Connector + คำสั่งลัด มัดรวมเป็นแพ็กเดียว ติดตั้งทีเดียวได้ทั้งชุด เหมาะกับการแจกให้ทั้งทีมใช้เหมือนกัน

Workshop #4 · Prompts

Workshop #4 — ลงมือทำ

Prompt 1 — สร้างข้อมูล
สุ่มยอดขาย 1000 รายการ โดยสมมติว่าเป็น "ร้านขายอุปกรณ์คอมพิวเตอร์" ที่มีอุปกรณ์ 100 ชนิด (100 barcode) จากนั้นบันทึกเป็นไฟล์ xlsx เพื่อใช้ในการฝึกวิเคราะห์ข้อมูล
Prompt 2 — วิเคราะห์ + สไลด์
จากไฟล์ที่สุ่มมา ช่วยสร้างสไลด์พรีเซนต์ให้ผู้บริหารหน่อย (ขอสวยๆ ธีมสี dark tone) ขอเป็นไฟล์ html

✅สังเกตอะไรบ้าง

· Cowork เขียนและรันโค้ดจริงเพื่อสุ่มข้อมูล — ไม่ใช่แค่พิมพ์ตัวเลขมั่ว

· Prompt 2 ไม่ต้องแนบไฟล์ซ้ำ เพราะ Cowork เห็นโฟลเดอร์อยู่แล้ว

· เปิดไฟล์ xlsx และ html ดูได้ทันทีจากโฟลเดอร์

Workshop #6 · Cowork

สรุปบันทึกการประชุมเป็นสไลด์ 📝

Prompt 1 — สร้างข้อมูลจำลอง (Role play)
ให้สมมติว่าตัวเองเป็นเลขาจดบันทึกการประชุม สร้างข้อความบันทึกการประชุม (rawdata) เกี่ยวกับ product ใหม่ที่ควรขายในปี 2027 เกี่ยวกับธุรกิจ "ขายเครื่องมือเกษตรราคาไม่เกิน 1500 บาท"
Prompt 2 — สรุปเป็นสไลด์
สรุปจากข้อความประชุมเป็นสไลด์นำเสนอ html

✅ใช้งานจริง

· งานจริง: เอาโน้ตประชุมจริง / transcript จาก Zoom มาแทน Prompt 1 ได้เลย

· เทคนิค Role ("สมมติว่าเป็นเลขา…") ช่วยให้ผลลัพธ์มีโครงสร้างแบบมืออาชีพ

Workshop #7 · Cowork

เขียนอีเมลสั้นๆ ถึงผู้บริหาร ✉️

  1. Export สไลด์จาก Workshop #6 เป็น PDFสั่ง Cowork แปลง html → pdf ให้ได้เลย
  2. สั่งเขียนอีเมลสรุปสั้นๆเชิญผู้บริหารเปิดอ่านไฟล์ PDF ที่แนบ — เน้นกระชับ ประเด็นชัด
ตัวอย่าง Prompt
ช่วยแปลงไฟล์สไลด์ html จาก workshop ก่อนหน้าเป็น pdf จากนั้นเขียนอีเมลสั้นๆ ถึงผู้บริหาร สรุปประเด็นสำคัญ 3 ข้อ และเชิญให้เปิดอ่านรายละเอียดในไฟล์ pdf ที่แนบ

✅บทเรียน

· งานต่อเนื่องหลายรูปแบบไฟล์ (html → pdf → email) จบใน Cowork ที่เดียว

· อีเมลผู้บริหารที่ดี: สั้น, บอกว่าต้องตัดสินใจอะไร, แนบรายละเอียดแยก

Workshop #8 · Cowork + Schedule

โจทย์: หาข้อมูล product ใหม่เพื่อขาย จากเว็บ Reddit / Etsy / Amazon

Prompt
Research หาข้อมูลเกี่ยวกับ "เครื่องมือเกษตรที่คนใช้งานบ่อยจากทั่วโลก" จากเว็บ reddit / etsy / amazon บันทึกเป็นไฟล์ .md พร้อมตั้งชื่อไฟล์ที่มีวันที่และเวลา และตั้งเวลาให้รันทุก 3 ชั่วโมง

🤖นี่แหละ Autonomous Work ของจริง

· Claude ค้นเว็บ → สรุป → บันทึกไฟล์ (ชื่อมีวันที่+เวลา ไม่ทับกัน) → ทำซ้ำเองทุก 3 ชม.

· คุณกลับมาเปิดโฟลเดอร์ทีเดียว มีรายงานรอเป็นชุด

· ประยุกต์: ติดตามราคาคู่แข่ง, ข่าวอุตสาหกรรม, รีวิวสินค้าตัวเอง

ก่อนจาก

กฎทอง 5 ข้อของการทำงานกับ AI

  1. สั่งให้ชัด เหมือนสั่งงานพนักงานใหม่บอกเป้าหมาย รูปแบบ และตัวอย่างที่ต้องการ
  2. ให้ AI ทำ ให้คุณตรวจผลงานสุดท้ายเป็นความรับผิดชอบของคุณเสมอ
  3. เริ่มเล็ก แล้วค่อยขยายทำ workflow ง่ายให้เวิร์คก่อน ค่อยเพิ่มความซับซ้อน
  4. ระวังข้อมูลลับคิดก่อนอัพโหลด และเลือกโฟลเดอร์งานแยกจากไฟล์สำคัญ
  5. ฝึกทุกวันทักษะ AI เหมือนขับรถ — เก่งได้ด้วยชั่วโมงบิน ไม่ใช่แค่ทฤษฎี
