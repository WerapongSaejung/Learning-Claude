# หลักสูตร 1 วัน: ใช้ AI ทำงานจริงด้วย Claude

หลักสูตรอบรมภายในสำหรับ **ผู้บริหาร บริษัท ที.พี. ดรัก แลบบอราทอรี่ (1969)**
เต็มวัน 09:00–16:30 · onsite · ผู้เรียน 5 ท่าน · วิทยากร 1 คน · ใช้ Claude Pro

## เป้าหมาย

1. **ใช้เป็นด้วยตัวเอง** — จบวันทุกท่านมี Claude Project ของงานตัวเอง 1 ชิ้น ที่ใช้ต่อได้วันจันทร์
2. **เห็นภาพระดับองค์กร** — เห็นว่าถ้า ที.พี. นำ AI เข้ามาจะเปลี่ยนอะไร และเสี่ยงตรงไหนภายใต้ GMP PIC/S

## โครงสร้างไฟล์

| ที่ | เนื้อหา |
|---|---|
| `docs/01-course-outline.md` | โครงหลักสูตรฉบับละเอียด — ต้นฉบับอ้างอิงของทุกอย่าง |
| `site/` | หน้าเว็บ 3 หน้า (สไลด์ / คู่มือวิทยากร / ใบงานผู้เรียน) สำหรับเผยแพร่เป็น Artifact |
| `dataset/` | ไฟล์ข้อมูลสมมติที่ผู้เรียนอัปโหลดเข้า Claude ใน workshop |
| `scripts/` | สคริปต์สร้าง dataset ขึ้นใหม่ (แก้ข้อมูลแล้ว generate ซ้ำได้) |

## ข้อควรรู้ก่อนใช้

- **ไฟล์ใน `dataset/` เป็นข้อมูลสมมติทั้งหมด** ชื่อบริษัทและชื่อผลิตภัณฑ์ใช้ของจริงเพื่อให้ผู้เรียนอิน แต่ตัวเลข ลูกค้า เหตุการณ์ และข้อร้องเรียนทั้งหมดแต่งขึ้นเพื่อการฝึกอบรม **ห้ามนำไปใช้อ้างอิงในงานจริง**
- **`site/facilitator-guide.html` มีสคริปต์และคำตอบที่เตรียมไว้** อย่าแชร์ให้ผู้เรียน
- ผู้เรียนใช้บัญชี Claude Pro ส่วนตัว ซึ่งไม่ได้อยู่ใต้สัญญาข้อมูลขององค์กร — กติกา 3 ถังในหลักสูตรต้องพูดตั้งแต่ต้นวัน ไม่ใช่ท้ายวัน
